📺 Kênh YouTube & tự đăng

Mỗi kênh có chủ đề và loại video riêng. App chạy nhiều luồng song song: chọn chủ đề hot → ⚡ làm tự động (video + thumbnail + tiêu đề/mô tả/tag + Shorts) → tải lên kênh. Có thể đặt giờ tự chạy mỗi ngày (máy phải đang mở app).

1. Kết nối Google

Hướng dẫn lấy Client ID (làm một lần, khoảng 5 phút)
  1. Vào Google Cloud Console, tạo một dự án mới.
  2. Mở YouTube Data API v3 → Enable. Làm tương tự với YouTube Analytics API (cho bảng 📊 Thống kê: thời gian xem, % xem hết, sub có thêm).
  3. Google Auth Platform → điền tên app + email → loại External. Ở mục Audience bấm Publish app (để “In production”, nếu để “Testing” thì 7 ngày phải đăng nhập lại).
  4. Clients → Create client → loại Desktop app → copy Client ID và Client secret dán vào dưới.
  5. Bấm “+ Kết nối kênh”, đăng nhập tài khoản Google của kênh. Gặp màn “Google chưa xác minh ứng dụng này” → Nâng cao → Đi tới … (không an toàn) (đây là app của chính bạn).
⚠ Giới hạn của Google: mỗi dự án Google Cloud có 10.000 đơn vị/ngày, tải 1 video tốn 1.600 → khoảng 6 video/ngày (tính cả Shorts) cho tất cả kênh dùng chung Client ID. Dự án chưa qua kiểm duyệt của Google thì video tải lên qua API bị khoá ở chế độ Riêng tư — bạn vào YouTube Studio đổi sang Công khai, hoặc gửi yêu cầu kiểm duyệt để bỏ khoá.

🍪 Cookie YouTube

Tải nhiều video, YouTube dễ tạm chặn máy bạn (“Sign in to confirm you're not a bot”) và video ra bị thiếu đoạn. Dùng cookie của một tài khoản YouTube đã đăng nhập thì ít bị chặn hơn nhiều.

⚠ Cookie = quyền đăng nhập tài khoản đó. Dùng một tài khoản Google phụ (không phải tài khoản kênh đăng video), không gửi file cookie cho ai, không dán vào chat. File lưu ở data/cookies.txt trên máy bạn (không đưa lên git).

Cách 1 — Tải file cookies.txt lên (khuyên dùng, chạy được mọi trình duyệt)

Hướng dẫn lấy file cookies.txt (khoảng 3 phút)
  1. Cài tiện ích Get cookies.txt LOCALLY: Chrome / Edge / Cốc Cốc · Firefox. Chọn đúng bản có chữ LOCALLY (bản “Get cookies.txt” không có chữ này từng bị gỡ vì gửi cookie ra ngoài).
  2. Cho tiện ích chạy ở cửa sổ ẩn danh: vào chrome://extensions → tiện ích → Chi tiết → bật Cho phép ở chế độ ẩn danh (Firefox: Tiện ích → Chạy trong cửa sổ riêng tư → Cho phép).
  3. Mở cửa sổ ẩn danh (Ctrl+Shift+N), vào youtube.com, đăng nhập tài khoản phụ, mở một video bất kỳ.
  4. Bấm biểu tượng tiện ích 🧩 → Get cookies.txt LOCALLY → Export (định dạng Netscape) → được file www.youtube.com_cookies.txt.
  5. Đóng ngay cửa sổ ẩn danh (đừng bấm đăng xuất — đăng xuất làm cookie mất hiệu lực). YouTube đổi cookie liên tục ở tab đang mở, đóng cửa sổ giúp file cookie dùng được lâu hơn.
  6. Bấm Chọn file dưới đây → Kiểm tra. Khi app lại báo bị chặn / cookie hết hạn (thường sau vài tuần) thì làm lại từ bước 3.

Cách 2 — Lấy thẳng từ trình duyệt trên máy này

Trình duyệt phải đang đăng nhập YouTube. Firefox chạy tốt nhất; Chrome / Edge bản mới mã hoá cookie nên thường không đọc được (khi đó dùng Cách 1). Trên Windows nên đóng hẳn trình duyệt trước khi bấm Kiểm tra.
